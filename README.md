# 🌐 Desenvolvimento de Identidade Digital

Este projeto consiste na criação de um website estático profissional que funciona como meu cartão de visitas digital e portfólio. O foco principal é a aplicação de fundamentos sólidos de desenvolvimento web, utilizando tecnologias puras para garantir performance e acessibilidade.

## 🚀 Objetivo do Projeto
Entregar uma interface de página única (SPA) que apresente minha biografia profissional, uma vitrine de projetos reais e canais diretos de contato, com foco total em **HTML5 Semântico** e **CSS3 Moderno**.

## 🛠️ Tecnologias Utilizadas
- **HTML5:** Estruturação semântica para melhor SEO e acessibilidade.
- **CSS3:** Estilização baseada em variáveis (`:root`), layouts responsivos e design fluido.
