Este repositório contém o código-fonte do meu portfólio profissional, desenvolvido como uma **Single Page Application (SPA)** estática. O projeto foi concebido para demonstrar o domínio de fundamentos essenciais de desenvolvimento web, priorizando semântica, desempenho e acessibilidade.

## 🎯 Proposta e Objetivo

O projeto tem como propósito central consolidar minha presença digital através de uma interface objetiva e profissional. A estrutura foi planejada para atender aos seguintes pilares estratégicos:

* **Exposição de Competências:** Apresentação formal da trajetória profissional e do conjunto de habilidades técnicas aplicadas ao desenvolvimento de software.
* **Vitrine de Projetos:** Curadoria de soluções reais que evidenciam a aplicação de boas práticas, organização de código e lógica de desenvolvimento.
* **Conectividade Profissional:** Disponibilização de canais de comunicação diretos para facilitar o networking e a prospecção de oportunidades no mercado de tecnologia.

## 📐 Design e Planejamento

O desenvolvimento técnico foi precedido por uma etapa de prototipagem para validar a arquitetura de informação e a interface do usuário (UI).

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica e organização do conteúdo para SEO e acessibilidade.
* **CSS3:** Estilização moderna com foco em responsividade e consistência visual.

## 📂 Estrutura de Arquivos

```bash
├── assets/
│   ├── documents/  # Documentação profissional (PDF)
│   ├── favicon/    # Manifesto e ícones multi-plataforma
│   ├── images/     # Ativos visuais otimizados
│   └── svg/        # Ícones e elementos gráficos vetoriais
├── index.html      # Marcação semântica principal
└── style.css       # Folha de estilo centralizada
```

## 🔧 Como visualizar o projeto

### 🔗 Online
O projeto está publicado e pode ser acessado diretamente via GitHub Pages:

<a href="https://github.com/JulioCSimoesP/identidade-digital" target="_blank" rel="noopener noreferrer"><strong>Acessar Identidade Digital</strong></a>

### 💻 Localmente
Caso deseje rodar o projeto em seu ambiente local:

1. Clone o repositório:

```Bash
git clone https://github.com/JulioCSimoesP/identidade-digital.git
```

2. Navegue até a pasta do projeto e abra o arquivo **index.html** em qualquer navegador ou utilize a extensão **Live Server** no VS Code para uma visualização em tempo real.
